# CardVault

Site vitrine simple pour la vente de jeux de cartes. HTML/CSS/JS pur, sans build.

## Développement local

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec n'importe quel serveur statique.

## Déploiement sur Netlify

1. Pousser ce repo sur GitHub/GitLab.
2. Sur [netlify.com](https://netlify.com), "Add new site" > "Import an existing project".
3. Choisir le repo. Build command: vide. Publish directory: `.`
4. Déployer.
